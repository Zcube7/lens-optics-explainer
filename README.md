# 镜头是怎么成像的

可交互的镜头成像原理演示页：焦距决定「看多宽」，光圈决定「进多少光、虚多少」。用可以拖动的示意图讲原理，再拿 20 支尼康 Z 卡口镜头的真实参数代进公式。

**在线打开：<https://zcube7.github.io/lens-optics-explainer/>**

纯静态页面，没有任何依赖和构建步骤。下载后双击 `index.html` 也能用。

## 板块

| 板块 | 内容 |
|---|---|
| 01 原理 | 小孔与透镜、薄透镜成像（可拖动物体）、焦距与视角、光圈与曝光、景深与虚化、透视压缩、衍射 |
| 02 尼康镜头 | 镜头名解码、镜片术语、Z / F 卡口剖面对比、焦段地图、20 支镜头图鉴（镜身轮廓等比例） |
| 03 虚拟取景器 | 一条傍晚的小路，换镜头、调光圈、走位、转动相机，画面的取景范围和每样东西的模糊量按公式现算 |
| 04 怎么选 | 按拍摄题材对应焦段和光圈，一键在取景器里看效果 |
| 05 速查 | 九个公式、五个常见误区 |

## 目录

```
index.html            页面结构与全部正文
css/style.css         样式
js/optics.js          光学公式（纯函数，页面里所有数字的唯一出处）
js/lenses.js          镜头、卡口、机身数据
js/util.js            SVG 拼装、对数滑块、事件总线
js/demo-*.js          板块一的六个演示
js/nikon.js           板块二与板块四
js/vf-scene.js        取景器里的场景：每样东西的画法、真实尺寸和位置
js/viewfinder.js      取景器：投影、逐物体模糊、控件
data/nikon_specs_verified.json   镜头参数的官网核对记录（含来源链接与各地区官网不一致之处）
tests/optics.test.js  自检
```

## 自检

```bash
node --test tests/optics.test.js
```

检查两件事：光学公式与手算值、尼康标称视角是否一致；`js/lenses.js` 里的数字是否与 `data/nikon_specs_verified.json` 逐项相同。

## 数据与模型说明

- 镜头参数取自尼康官网产品规格页（全球站、中国站，部分镜头另核对了美国站），2026 年 11 月核对。带脚架环的变焦镜头，重量取不含脚架环的数值。
- 光学计算用薄透镜近似，目的是讲清原理。真实镜头的呼吸效应、口径蚀、像差没有计入，数值与实拍会有出入。
- 浮动光圈变焦镜头在中间焦距的最大光圈是按两端插值的近似值。
- 镜身轮廓和取景器场景都是示意图，不是产品外观。
