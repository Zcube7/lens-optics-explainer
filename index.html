01

原理

镜头只做一件事：把物体上每个点发出的光，重新汇聚成传感器上的一个点。下面六个小节都是这句话的展开。

1.1从小孔到透镜

在暗箱上开一个小孔，外面的景物就会倒着投在对面的墙上——每个物点只有一条细光束能穿过小孔，落在唯一的位置。孔越小像越清楚，但也越暗。透镜解决了这个矛盾：它把同一个物点发出的一大束光折回同一个点。

代价是：透镜只能让某一个距离上的物体精确汇聚。物距 u、像距 v、焦距 f 满足 1/f = 1/u + 1/v。拖动下图里的物体试试。

  • 焦距的定义。物体在无穷远时 v = f。焦距就是「无穷远的像离镜片多远」。
  • 对焦在做什么。物体靠近，像面后移。对焦就是移动镜片组，让像重新落回传感器。
  • 最近对焦距离。物体越近，镜片要伸出越多；u 小于 f 时光线不再汇聚，只剩放大镜式的虚像。
  • 1:1 微距。u = 2f 时像和物一样大，这是微距镜头的工作位置。

1.2焦距决定视角

传感器的大小是固定的。焦距越长，传感器离镜头的光学中心越远，它「张开」的角度就越小：视角 = 2·arctan( 传感器边长 / 2f )。视角窄，等于把远处的一小块景物铺满整个画面。

1.3光圈：进光量的阀门

镜头里有一组可以开合的叶片。从前面看进去，那个透光的孔叫入瞳，直径记作 D。光圈值是一个比值：N = f / D，写作 f/N。N 越小孔越大。因为是比值，同样是 f/2.8，24mm 镜头只要 8.6mm 的孔，400mm 镜头要 143mm。

1.4景深与虚化

只有对焦平面上的点能汇聚成点。更远或更近的点，光束在传感器前面或后面才交汇，落到传感器上就摊成一个圆，叫模糊圆。模糊圆小到看不出来（FX 画幅约 0.03mm）的那一段距离就是景深；远大于这个尺寸，就是虚化。

  • 虚化量的三个来源。模糊圆 = 入瞳直径 × 主体放大倍率 × 背景离焦比例。所以：光圈开大、焦距变长、靠近主体、让背景离远，都会更虚。
  • 超焦距。对焦在超焦距上，从它的一半到无穷远都落在景深里。风光摄影常用：20mm f/8 的超焦距只有 1.7 米。
  • 景深不是一刀切。清晰到模糊是渐变的，0.03mm 只是约定的界线。高像素机身放大看，实际能用的景深更浅。

1.5透视：变的是距离，不是焦距

远近物体在画面里的大小比例只取决于相机站在哪。所谓长焦「压缩空间」，是因为要把主体拍成同样大，长焦得退得很远——这时主体和背景到相机的距离差不多，背景就显得又大又近。

1.6衍射：光圈也不能太小

光穿过小孔会散开。即使镜头完美无缺，一个点成的像也是一个小光斑（艾里斑），直径约 2.44 · λ · N，只跟光圈值有关。光斑比像素大出太多时，再收光圈只会让整张照片变软。

尼康镜头

尼康无反相机用 Z 卡口，镜头品牌叫尼克尔（NIKKOR）。下面先讲名字怎么读，再把 20 支镜头的真实参数代进上面的公式。

2.1镜头名怎么读

名字里每一段都是一个参数。点一下看含义。

2.2Z 卡口：大口径、短法兰距

卡口内径决定最后一片镜片能做多大，法兰距（卡口到传感器的距离）决定它能离传感器多近。Z 卡口内径 55mm、法兰距 16mm；用了近 60 年的 F 卡口是 47mm 和 46.5mm。

F 卡口镜头装上 FTZ 转接环就能用——转接环的厚度正好补上 30.5mm 的法兰距差。

05

速查

成像公式1/f = 1/u + 1/vu 物距，v 像距。无穷远时 v = f。
放大倍率m = v/u = f/(u − f)m = 1 即 1:1 微距，此时 u = 2f。
视角θ = 2·arctan(d / 2f)d 取传感器的宽、高或对角线。FX：36 / 24 / 43.3mm。
光圈值N = f / DD 入瞳直径。进光量 ∝ 1/N²。
曝光值EV = log₂(N² / t)t 快门秒数（ISO 100）。EV 加 1 = 光少一半。
超焦距H = f²/(N·c) + fc 容许模糊圆：FX 0.03mm，DX 0.02mm。
景深近点 = s(H−f)/(H+s−2f) 远点 = s(H−f)/(H−s)s 对焦距离。s ≥ H 时远点为无穷远。
模糊圆c = (f²/N)·|d−s| / (d·(s−f))对焦在 s，距离 d 处的点在传感器上的光斑直径。
艾里斑直径 ≈ 2.44·λ·Nλ = 550nm 时约 1.34·N 微米。
焦距越长，景深越浅

只在站着不动时成立。如果把主体拍成一样大（长焦退远），同样光圈值下景深几乎一样。长焦显得更虚，是因为它把背景连同模糊一起放大了。

长焦镜头会压缩空间

压缩来自拍摄距离。站在同一个位置用广角拍，再把中间裁出来，透视和长焦拍的完全一样，只是像素少了。

光圈越小，照片越清晰

收小光圈景深变大，但衍射也变强。高像素机身上 f/16 的整体锐度明显不如 f/5.6。

等效焦距就是镜头焦距变了

焦距是镜头的物理属性，装到哪台机身上都不变。DX 机身只是用更小的传感器截取了画面中间，视角相当于 1.5 倍焦距；虚化量也要按光圈值乘 1.5 来对比（DX 上 f/1.8 ≈ FX 上 f/2.8 的虚化）。

同样是 f/2.8，大镜头进光更多

就单位面积的亮度（也就是曝光）来说，f/2.8 都一样，快门和 ISO 不用变。镜头大是因为焦距长，要凑出同样的比值就需要更大的孔。
